# @qcard/host

[qcard](https://qcard.dev)의 호스트 에이전트입니다. qcard는 스펙 문서로 앱 버전별 QA 문서를 만들고, Agent가 Android 기기에서 테스트 케이스를 직접 수행하는 QA 자동화 서비스입니다.

이 패키지를 설치한 PC가 실제 실행을 맡습니다.

- 웹에서 만든 테스트 사이클을 이 PC에 USB로 연결한 Android 기기에서 실행하고, 결과와 스크린샷을 웹에 올립니다.
- 웹에서 요청한 QA 문서 생성을 처리합니다.
- LLM은 이 PC에 로그인된 **본인의 Claude Code**로 부릅니다. API 키는 쓰지 않고, 사용량은 본인 Claude 플랜에서 차감됩니다.

## 준비물

| 필요한 것            | 설치                                                                                                                                           |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| macOS                | 지금은 macOS만 지원합니다                                                                                                                      |
| Node.js 22 이상      | https://nodejs.org 또는 `brew install node`                                                                                                    |
| adb                  | `brew install android-platform-tools`                                                                                                          |
| Claude Code (로그인) | https://claude.com/claude-code 설치 후 터미널에서 `claude`로 로그인                                                                            |
| scrcpy (선택)        | `brew install scrcpy` — 로컬 콘솔에서 기기 화면을 실시간으로 봅니다                                                                            |
| Android 기기         | 개발자 옵션의 USB 디버깅을 켜고 PC에 연결합니다. 한글 입력이 필요한 케이스는 [ADBKeyboard](https://github.com/senzhk/ADBKeyBoard)를 설치합니다 |

## 시작하기

```sh
npm i -g @qcard/host

qcard doctor     # 준비물 점검
qcard connect    # 브라우저가 열리면 [이 PC 연결]을 누릅니다
qcard serve      # 호스트 에이전트를 켭니다
```

1. 먼저 [qcard 웹](https://qcard.dev)에 GitHub로 로그인합니다.
2. `qcard connect`를 실행하면 브라우저에 연결 화면이 열립니다. **이 PC의 터미널에서 직접 시작한 경우에만** [이 PC 연결]을 누르세요. 연결 정보는 macOS 키체인에 저장됩니다.
3. `qcard serve`를 켜 두면 로컬 콘솔 주소가 출력됩니다. 콘솔에서 기기 화면을 보고, 사이클을 골라 Run을 시작합니다. 웹에서 요청한 Run과 QA 문서 생성도 이 PC가 받아 처리합니다.

## 명령

| 명령               | 하는 일                                                           |
| ------------------ | ----------------------------------------------------------------- |
| `qcard connect`    | 이 PC를 qcard 계정에 연결합니다. 이미 연결돼 있으면 그대로 둡니다 |
| `qcard status`     | 연결된 계정과 PC 이름을 확인합니다                                |
| `qcard disconnect` | 이 PC의 연결을 해제하고 보관한 연결 정보를 지웁니다               |
| `qcard serve`      | 호스트 에이전트를 켭니다. `Ctrl+C`로 끕니다                       |
| `qcard doctor`     | adb, Claude Code, scrcpy를 점검합니다                             |
| `qcard --help`     | 도움말                                                            |

`qcard connect` 옵션:

- `--force`: 이미 연결돼 있어도 다시 연결합니다 (다른 계정으로 바꿀 때). 새로 연결되면 예전 연결은 해제합니다

`qcard serve` 옵션:

- `--serial <시리얼>`: 기기가 여러 대일 때 사용할 기기 (기본: 처음 연결된 기기)
- `--allow-network`: Agent가 기기의 네트워크를 끄는 동작을 허용합니다
- `--headless`: 로컬 콘솔 없이 실행합니다

## 이 PC와 기기에서 하는 일

- **Claude Code로 보내는 것**: 테스트 대상 앱의 화면 구조(접근성 트리)와, Agent가 요청할 때만 스크린샷을 보냅니다. 대상 앱이 화면 맨 앞에 없으면 스크린샷을 보내지 않습니다.
- **기기 설정**: Run 동안 "충전 중 화면 켜짐 유지"를 켜고, 끝나면 원래대로 되돌립니다. 잠긴 기기의 잠금을 풀지는 않습니다. Run을 시작할 때 잠금이 풀려 있어야 합니다.
- **앱 설치와 데이터**: 사이클에 올라온 빌드(APK)가 기기의 앱과 다르면 내려받아 설치합니다. 앱 데이터를 지워야 하는 경우(낮은 버전, 다른 서명)에는 자동으로 하지 않고 멈춥니다. 앱 데이터 초기화는 실행 대상 앱에만 합니다.
- **연결 해제**: 웹의 [연결된 PC]에서 해제하면 이 PC는 바로 qcard에 접근할 수 없습니다. PC를 잃어버렸을 때도 웹에서 해제하세요.
- **로컬 저장**: 업로드 대기 중인 결과는 `~/.qcard/`에 두었다가 네트워크가 돌아오면 이어서 보냅니다.

## 문제 해결

- **"이 PC가 qcard 계정에 연결되지 않았습니다"**: `qcard connect`로 다시 연결합니다.
- **"이미 연결되어 있습니다"**: 이 PC는 이미 연결된 상태라 그대로 `qcard serve`를 켜면 됩니다. 다른 계정으로 바꾸려면 `qcard connect --force`를 실행합니다.
- **[연결된 PC]에 같은 PC가 여러 개 보임**: 0.1.1 이하 버전에서 `qcard connect`를 여러 번 실행해 생긴 예전 연결입니다. 쓰지 않는 연결은 웹에서 해제하세요.
- **연결 화면에서 "연결할 수 없습니다"**: 브라우저 탭을 닫고 터미널에서 `qcard connect`를 다시 실행합니다. 연결 화면 주소는 한 번만 쓸 수 있습니다.
- **기기가 보이지 않음**: `adb devices`에 기기가 `device` 상태로 나오는지 확인합니다. `unauthorized`면 기기 화면에서 USB 디버깅을 허용합니다.
- **Run이 "일시정지"됨**: 기기 화면이 꺼졌거나 잠겼거나, Claude 플랜 사용량 한도에 닿은 경우입니다. 원인을 해결한 뒤 로컬 콘솔이나 웹에서 이어서 실행합니다.
- **로컬 콘솔 주소가 열리지 않음**: 주소는 한 번만 쓸 수 있습니다. `qcard serve`가 떠 있는 터미널에서 Enter를 누르면 새 주소가 나옵니다.
