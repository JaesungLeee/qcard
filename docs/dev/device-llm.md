# 실기기·실제 모델 명령

개인 폰(SM-S711N)에 연결해 쓰는 명령과 실제 모델을 부르는 명령. 실제 모델 호출은 사용자 플랜 사용량을 쓴다. LLM 모드·제공자 규칙은 `.claude/rules/llm.md`.

## 실기기

| 명령                                                                          | 내용                                                                                                                                                                                                                          |
| ----------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm device:check`                                                           | 연결·기기 정보·앱 설치·IME·덤프 속도 점검. 읽기 전용                                                                                                                                                                          |
| `pnpm device:record <화면 이름> [--set <묶음>]`                               | 지금 화면(스크린샷 + 트리)을 `packages/device/recordings/`에 저장(커밋 안 함, 읽기 전용 명령만 씀)                                                                                                                            |
| `pnpm --filter @qcard/agent device-run <TC-ID…> [--package com.example.harukong.qa]` | 실기기에서 케이스 실행(실제 모델). 플랜 한도·로그인 만료면 일시정지하고 `--resume <실행 id>`로 이어 간다. 결과·스크린샷은 `packages/agent/runs/`(커밋 안 함, `pnpm dev`에서 "로컬 실행"으로 보임). 지정한 앱만 `pm clear`한다 |

사이클 단위로 돌리고 Firestore에 올리는 경로는 [host-agent.md](host-agent.md).

## 실제 모델

| 명령                                         | 내용                                                                                                                                                                                                                |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pnpm llm:smoke`                             | Claude Code 설치·로그인 상태와 실제 모델의 도구·출력 스키마 확인(호출 2번)                                                                                                                                          |
| `pnpm --filter @qcard/agent record [TC-ID…]` | e2e 케이스를 실제 모델로 다시 녹화(`packages/agent/cassettes/<케이스>/`). Agent 프롬프트·도구·관찰 형식을 바꾸면 요청이 달라져 재생 테스트가 실패하므로 다시 녹화한다. `--live`면 녹화 파일을 쓰지 않고 돌려만 본다 |
| `pnpm --filter @qcard/agent sample-runs`     | ui:snap용 로컬 실행 샘플(`apps/web/e2e/runs-sample/`)을 녹화 재생으로 다시 만든다(호출 없음). Agent 결과 형식을 바꾸면 돌린다                                                                                       |

다시 녹화하는 전체 절차는 `/rerecord` skill.

## 환경변수

- `LLM_MODE=replay`(기본, 녹화 없으면 실패)·`record`·`live`
- `LLM_PROVIDER=claude-cli`(기본, 본인 Claude Code)·`api`(`ANTHROPIC_API_KEY`, 비용 발생)
