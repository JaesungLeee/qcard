# 로컬 콘솔과 진행 상태 공유

라이브 화면과 실행 제어는 실행자 PC의 **로컬 콘솔**에서만 한다. 화면은 서버를 거치지 않고 디바이스에서 바로 받는다. 팀은 웹 대시보드에서 진행 상태를 실시간으로 본다.

코드: 서버 `apps/host-agent/src/console/`, 화면 `apps/web/src/features/console`, 메시지 형식 `packages/shared/src/console.ts`. 실행 명령은 [dev/host-agent.md](../dev/host-agent.md).

## 로컬 콘솔

- **라이브 디바이스 화면**: scrcpy H.264 스트림을 브라우저에서 WebCodecs로 디코딩한다. Chrome 계열에서만 된다. 콘솔을 보는 동안에만 scrcpy를 띄운다.
- **액션 오버레이**: 화면 위에 Agent가 누른 위치·대상 요소 박스를 실행 후 1.5초 동안 보인다.
- 현재 케이스·스텝 하이라이트, 진행률, 경과 시간.
- **Agent 사고 로그**: 무엇을 보고 왜 이 액션을 했는지.
- **제어**: 일시정지 / 재개 / 스텝 건너뛰기 / 중단 / **Take over** 후 Agent에 반환. 실행자가 디바이스를 직접 만져 개입해도 된다. Take over·스텝 건너뛰기가 있으면 Pass를 자동 확정하지 않는다.
- 위험 액션 승인, 수동 스텝 완료는 여기서만 한다.
- **Claude Code 상태**: 상단 칩에 설치·로그인·업데이트 필요·플랜 한도를 보이고, 문제가 있으면 해결 방법(예: 터미널에서 다시 로그인)을 안내한다. 문제를 알면 실행 버튼을 끈다.
- 홈에서 [케이스 고르기]로 Run을 시작한다([cycles.md](cycles.md#실행-케이스-고르기)).

## 웹에서 로컬 콘솔 열기

호스트가 연결 신호에 일회용 콘솔 주소(2분·1회)를 실어 보내고, 웹 사이드바 [로컬 콘솔]이 새 탭으로 연다. 주소는 본인만 읽는 호스트 문서로만 전달한다. 호스트가 꺼져 있으면 `qcard serve`로 켜는 방법을 보인다. 보호 방식은 [security.md](../security.md#로컬-콘솔-보호).

## 팀 진행 상태 공유

웹 대시보드에 사이클 진행 매트릭스, 실행 중 Run의 현재 케이스, 판정 결과를 실시간으로 반영한다(Firestore 구독). 라이브 화면은 공유하지 않는다. 일시정지 중이면 이유를 함께 보인다.
