# 프로젝트·멤버·사용량

**프로젝트 = QA 대시보드 1개**(앱 하나)다. 멤버·권한·데이터는 프로젝트 단위로 나뉘고, 다른 프로젝트의 데이터는 보이지 않는다. 조직 계층은 없다.

코드: 규칙 `packages/shared/src/membership.ts`, Functions `apps/functions/src`, 화면 `apps/web/src/features/projects`·`features/hosts`. 보안 규칙은 `firebase/`.

## 로그인

- **GitHub 계정 단일**(Firebase Auth GitHub 제공자)이고, **웹 로그인 페이지에서만** 로그인한다.
- 로그인하지 않고 다른 주소(초대 링크·호스트 연결 화면 등)로 들어오면 로그인 페이지를 거쳐 원래 주소로 돌아간다. 로그인한 상태로 로그인 페이지에 오면 프로젝트 목록으로, 로그아웃하면 로그인 페이지로 간다.
- 로그인 후 첫 화면은 **내가 속한 프로젝트 목록**이다.

## 역할

| 역할   | 할 수 있는 일                                                                                                  |
| ------ | -------------------------------------------------------------------------------------------------------------- |
| Admin  | QA의 모든 일 + 멤버 초대·역할 변경·내보내기, 실행 안전장치 설정, GitHub 저장소 연결·담당자 매핑, 프로젝트 삭제 |
| QA     | 편집·실행·확정, 결함 이슈 발행                                                                                 |
| Viewer | 조회                                                                                                           |

Firestore 보안 규칙이 강제한다. 프로젝트에는 Admin이 늘 1명 이상 있다.

## 생성·초대·탈퇴·삭제

- **생성**: 로그인한 사용자 누구나. 만든 사람이 Admin이다.
- **초대**: Admin이 역할을 정해 GitHub 사용자명이나 초대 링크로 초대한다. **7일 뒤 만료**된다. 받은 사람이 수락해야 멤버가 된다. 사용자명 초대는 한 번만, 링크 초대는 만료·취소 전까지 여러 명이 쓴다. 사용자명 초대도 받는 사람에게 알림이 가지 않으므로 링크를 직접 전해야 한다.
- **데이터 처리 안내**: 프로젝트를 만들거나 참여할 때, 스펙·화면 데이터가 **실행한 사용자 본인의 Claude 계정**으로 Anthropic에 전송되고 그 계정의 데이터 정책이 적용됨을 안내하고 확인받는다([security.md](../security.md#전송-제한)).
- **탈퇴**: 멤버는 언제든 탈퇴한다. 마지막 Admin은 다른 멤버에게 Admin을 넘긴 뒤에만 탈퇴한다(혼자면 탈퇴 대신 프로젝트 삭제). 그 사람이 남긴 판정·이력은 남는다.
- **삭제**: Admin만, 프로젝트 이름을 입력해 확인한다. **30일** 동안 삭제 예정으로 남고 Admin이 복구할 수 있다. 지나면 예약 Functions가 Firestore 문서와 Storage 파일을 영구 삭제한다.

## 호스트 연결

호스트 에이전트는 GitHub로 따로 로그인하지 않고, 웹에서 실행자 계정에 연결한다.

- `qcard connect`가 브라우저로 웹의 연결 화면(일회용 주소)을 열고, 로그인한 사용자가 [이 PC 연결]을 누르면 그 계정의 **호스트 자격**이 발급돼 PC의 키체인에 저장된다.
- 이미 연결된 PC에서 다시 연결하면 새 연결을 만들지 않는다. 강제로 다시 연결하면(다른 계정으로 바꿀 때) 예전 연결을 해제해 PC 하나에 연결이 하나만 남는다.
- 호스트는 켤 때마다 자격으로 짧은 수명의 **호스트 토큰**을 받는다.
- 웹에서 내 계정에 연결된 PC 목록(이름·연결 시각·마지막 접속)을 보고 연결을 해제할 수 있다. 해제하면 그 PC는 즉시 쓰기·토큰 발급이 막힌다.
- 웹 로그아웃은 호스트 연결에 영향이 없다.

## GitHub 저장소

- Admin이 프로젝트 설정에서 GitHub 저장소 **1개**를 qcard GitHub App으로 연결하고, **스펙 이름 → 담당자** 표를 정한다. 결함을 이 저장소의 이슈로 발행하고 상태를 맞춘다. 규칙은 [issues.md](issues.md).
- 연결하지 않아도 결함은 qcard 안에서 그대로 관리한다.

## 사용량

- LLM 사용량을 케이스·QA 문서 생성 단위로 **토큰 수 + API 환산 비용**으로 보인다. 실제 청구액이 아니라 실행자 본인의 플랜에서 차감된다는 점을 라벨로 구분한다.
- 프로젝트 단위 예산은 없다. 비용은 각 사용자의 플랜에서 나가므로, 폭주는 [실행 안전장치](execution.md#실행-안전장치)로, 플랜 한도는 [일시정지](execution.md#일시정지)로 다룬다.
