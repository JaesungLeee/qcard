### 유저 플로우 1 - 온보딩을 처음부터 끝까지 밟는다

처음 설치한 사용자가 닉네임을 정하고, 첫 습관을 만들고, 메이트를 초대한 뒤, 사용법 안내를 거쳐 오늘 탭에 도착한다.

1. 앱을 처음 켜면 스플래시 뒤 닉네임 설정 스텝이 열린다
2. 닉네임을 입력하고 [저장]을 누르면 첫 습관 만들기 스텝이 열린다
3. 습관 이름을 입력하고 [습관 만들기]를 누르면 메이트 초대 스텝이 열린다
4. [X]를 누르면 사용법 안내 스텝 1이 열린다
5. 안내 스텝 5에서 `하루콩 시작하기`를 누르면 온보딩이 끝나고 오늘 탭이 열린다

**완료 조건**: 이 앱 설치에 닉네임과 습관 1개가 있고, 온보딩이 완료로 기록되어 오늘 탭과 바텀 네비게이션이 보인다.

## 2. 요구사항 (Requirements) _(필수)_

### 2.1 기능적 요구사항 (Functional Requirements)

**스텝 구성과 진행**

- **FR-001**: 시스템은 반드시 온보딩을 `닉네임 설정` → `첫 습관 만들기` → `메이트 초대` → `사용법 안내` 순서로 진행하며, 앞 스텝을 끝내야 뒤 스텝을 연다.
- **FR-002**: 시스템은 반드시 닉네임 설정 스텝에 건너뛰기 수단을 두지 않으며, 닉네임 저장에 성공해야만 다음 스텝을 연다.
- **FR-003**: 시스템은 반드시 첫 습관 만들기 스텝에 [건너뛰기]를 보여 주고, 누르면 습관을 만들지 않은 채 사용법 안내 스텝을 연다.
- **FR-004**: 시스템은 반드시 첫 습관 만들기 스텝에서 습관을 만든 사용자에게만 메이트 초대 스텝을 보여 주고, 만들지 않은 사용자에게는 보여 주지 않는다.
- **FR-005**: 시스템은 반드시 온보딩의 모든 스텝에서 바텀 네비게이션을 숨기고, 온보딩이 끝나 오늘 탭에 들어가는 순간부터 보여 준다.
- **FR-006**: 시스템은 반드시 온보딩의 모든 스텝에서 앞 스텝으로 돌아가는 뒤로가기 버튼을 두지 않는다. 메이트 초대 스텝도 마찬가지다.
- **FR-007**: 시스템은 반드시 시스템 뒤로가기(제스처·물리 키)로 이미 끝낸 앞 스텝으로 돌아가지 않게 한다. 사용법 안내 스텝 2~5에서만 한 스텝 앞(스텝 N-1)으로 가고, 그 밖의 모든 지점 — 닉네임 설정·첫 습관 만들기·메이트 초대 스텝과 안내 스텝 1 — 에서는 **앱을 백그라운드로 보낸다.** 온보딩을 끝내거나 오늘 탭으로 보내지 않는다.

**메이트 초대**

- **FR-008**: 시스템은 반드시 메이트 초대 스텝에 들어갈 때 바로 앞 스텝에서 만든 습관의 초대 링크를 받아 둔다.
- **FR-009**: 시스템은 반드시 메이트 초대 스텝에 제목 `함께할 메이트를 불러볼까요?`와 본문 `혼자 하면 사흘, 같이 하면 습관이 돼요. 메이트가 들어오면 서로의 체크를 응원할 수 있어요.`를 보여 준다.
- **FR-010**: 시스템은 반드시 메이트 초대 스텝에서 메이트 목록을 보여 주지 않는다.
- **FR-011**: 시스템은 반드시 [메이트 초대하기]를 누르면 초대 링크를 담아 OS 공유 시트를 열고, 시트를 닫은 뒤에도 메이트 초대 스텝을 그대로 둔다. 공유 성공 여부로 스텝을 넘기지 않는다.
- **FR-012**: 시스템은 반드시 [초대 링크 복사]를 누르면 초대 링크를 클립보드에 복사하고 복사 완료 토스트를 보여 주며, 메이트 초대 스텝을 그대로 둔다. 복사했다고 다음 스텝을 열지 않는다.
- **FR-013**: 시스템은 반드시 메이트 초대 스텝 오른쪽 위에 [X]를 두고, 누르면 사용법 안내 스텝 1을 연다. 이 스텝을 나가는 수단은 [X] 하나이며 [건너뛰기] 텍스트 버튼은 두지 않는다.

**사용법 안내**

- **FR-014**: 시스템은 반드시 사용법 안내를 5스텝으로 만들고, 스텝마다 스텝 번호·안내 문구·예시 이미지를 함께 보여 준다. 안내 문구는 순서대로 `오늘 탭에서 습관 카드를 눌러 체크해요` / `카드를 길게 누르면 한 줄 메모를 남겨요` / `연속 기록이 쌓이면 콩이 자라요` / `기록 탭에서 주간 리포트를 확인해요` / `작은 습관부터 오늘 바로 시작해요` 다.
- **FR-015**: 시스템은 반드시 사용법 안내 아래에 dot 5개를 두고 현재 스텝 하나만 선택 상태로 보여 준다.
- **FR-016**: 시스템은 반드시 dot을 눌러 그 스텝으로 바로 갈 수 있게 한다. 앞 스텝으로 돌아가는 이동도 된다.
- **FR-017**: 시스템은 반드시 사용법 안내 스텝 1~4에서 상단에 [건너뛰기]를 보여 주고 하단 버튼은 두지 않는다.
- **FR-018**: 시스템은 반드시 사용법 안내 스텝 5에서 상단 [건너뛰기]를 숨기고 하단 버튼 `하루콩 시작하기`를 보여 준다.
- **FR-019**: 시스템은 반드시 사용법 안내의 [건너뛰기]나 `하루콩 시작하기`를 누르면 온보딩을 끝내고 오늘 탭을 연다.
- **FR-020**: 시스템은 반드시 사용법 안내의 예시 이미지를 눌러도 반응하지 않는 그림으로만 다루며, 안내를 보는 동안 습관을 체크하거나 메모를 만들지 않는다.

**완료와 재개**

- **FR-021**: 시스템은 반드시 온보딩 완료 표시가 기록된 앱 설치에서 온보딩을 다시 보여 주지 않는다.
- **FR-022**: 시스템은 반드시 이 앱 설치에 기록된 **온보딩 완료 표시**로 완료 여부를 정한다. 닉네임이 있어도 완료 표시가 없으면 온보딩을 끝내지 않은 것으로 보고 온보딩을 연다. 스플래시는 이 판정을 그대로 따라 온보딩과 오늘 탭 중 하나를 연다.
- **FR-023**: 시스템은 반드시 온보딩을 끝내지 못하고 앱이 꺼졌다 다시 켜지면 **마지막으로 머문 스텝**부터 이어 간다. 이미 끝낸 앞 스텝은 다시 보여 주지 않고, 이미 저장한 닉네임·습관을 다시 만들지 않는다.
- **FR-024**: 시스템은 반드시 온보딩 스텝을 옮길 때마다 현재 스텝을 이 앱 설치에 기록하고, 오늘 탭으로 나가는 순간 온보딩 완료 표시를 기록한다.

### 2.2 핵심 UX 규칙 (Core UX Rules)

- **UX-001**: 이미 끝낸 스텝의 결과(닉네임·습관)는 뒤 스텝의 조작이나 앱 재실행으로 취소되거나 다시 만들어지지 않는다. 온보딩을 한 번 거치는 동안 닉네임 1개, 습관 최대 1개만 만들어진다.
- **UX-002**: 온보딩의 모든 스텝에는 다음 스텝으로 가는 버튼이 늘 화면에 있다. 닉네임 설정 스텝의 [저장]만 규칙에 맞는 입력 전까지 꺼져 있고, 나머지 스텝의 버튼은 들어온 순간부터 켜져 있다.
- **UX-003**: 초대 링크 복사 토스트는 화면 하단에서 40px 위에 보여 준다.
- **UX-004**: 사용법 안내 스텝을 옮길 때 안내 문구·예시 이미지·dot 선택 위치가 함께 바뀌며, 서로 다른 스텝을 가리키는 상태가 화면에 남지 않는다.
- **UX-005**: 스텝을 바꾸는 조작을 연달아 해도 같은 스텝이 두 번 열리지 않는다. 온보딩의 스텝 전환은 모두 사용자의 조작으로만 일어나며, 시간이 지나 저절로 넘어가는 스텝은 없다.
- **UX-006**: 온보딩 중에는 남은 스텝 수나 진행률을 알리는 표시를 두지 않는다. 사용법 안내의 dot만이 유일한 진행 표시다.

## 3. 범위 (Scope) _(필수)_

- 대상: 앱을 처음 설치해 켠 사용자, 온보딩을 끝내지 못하고 앱을 다시 켠 사용자
- 비목표: 닉네임 규칙(계정 스펙), 습관 만들기 화면의 세부 입력(습관 스펙), 초대 링크를 받은 쪽의 흐름(메이트 스펙)

## 4. 가정 (Assumptions)

- 닉네임은 2~10자 한글·영문·숫자다.
- 초대 링크는 서버에서 받아 오며, 네트워크가 없으면 받지 못한다.
