# IconButton

아이콘 하나로 동작을 나타내는 버튼.

## qcard에서 쓰는 법

- 반드시 `aria-label`을 준다(예: "알림", "펼치기").
- 표 행 펼치기·닫기·검색 등 의미가 분명한 아이콘에만 쓴다.
- 툴바에서는 `variant="outlined"`, 헤더에서는 `normal`.

## 출처

Montage `@montage-ui/core` 4.1.3의 `IconButton`(`packages/core/src/components/icon-button`)을 그대로 번들했습니다. 전체 props는 `index.d.ts`의 `IconButtonProps`를 봅니다.
