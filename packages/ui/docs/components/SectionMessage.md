# SectionMessage

구획 안에 머무는 안내·경고 메시지.

## qcard에서 쓰는 법

- 승인 보류(스펙 확인 질문 미답변), 자동 확정 불가 사유, Wi-Fi ADB로 인한 Blocked 안내처럼 그 자리에서 읽어야 하는 설명에 쓴다.
- 변형: `info`(일반), `cautionary`(보류·확인필요), `negative`(실패), `positive`(완료).

## 출처

Montage `@montage-ui/core` 4.1.3의 `SectionMessage`(`packages/core/src/components/section-message`)을 그대로 번들했습니다. 전체 props는 `index.d.ts`의 `SectionMessageProps`를 봅니다.
