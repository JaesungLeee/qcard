# SegmentedControl

같은 데이터를 다른 방식으로 보는 전환 컨트롤.

## qcard에서 쓰는 법

- 2~4개 보기 전환(예: 표 / 매트릭스, 라이트 / 다크)에 쓴다.
- 화면 구획을 바꾸는 탭은 Tab을 쓴다.

## 출처

Montage `@montage-ui/core` 4.1.3의 `SegmentedControl`(`packages/core/src/components/segmented-control`)을 그대로 번들했습니다. 전체 props는 `index.d.ts`의 `SegmentedControlProps`를 봅니다.
