# TextField

한 줄 텍스트 입력.

## qcard에서 쓰는 법

- 케이스 검색, 닉네임 같은 짧은 값 입력에 쓴다.
- 검증 실패는 `status="negative"`와 함께 아래 안내 문구를 둔다.
- 반드시 `<label>`을 연결한다.

## 출처

Montage `@montage-ui/core` 4.1.3의 `TextField`(`packages/core/src/components/text-field`)을 그대로 번들했습니다. 전체 props는 `index.d.ts`의 `TextFieldProps`를 봅니다.
